# ControlRepo

ControlRepo stores version metadata used by **Surge Manager**.

## Format

```json
[
  {
    "discord": 320012,
    "surge": "1.0.1"
  }
]
```

## Fields

- `discord` — Discord RNA version code Surge Manager should prefer.
- `surge` — SurgeCord metadata version marker.
